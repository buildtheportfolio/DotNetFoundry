## Category Guide

### Console
Small command-line applications for C# fundamentals, parsing, validation and automation.

### ASP.NET Core
REST APIs covering routing, middleware, validation, pagination, error handling and observability concepts.

### Minimal API
Focused API implementations using the minimal hosting model.

### Blazor
Interactive web applications and component-focused projects using Blazor.

### Entity Framework Core
Persistence, querying, transactions, concurrency and data-access patterns.

### Security
Authentication, authorization, tokens, claims and secure API boundaries.

### Background Services
Workers, scheduled processing, queues and long-running services.

### Real-Time
SignalR and event-driven user experiences.

### Architecture
Dependency injection, boundaries, messaging and application structure.

### Design Patterns
Practical implementations of GoF and enterprise patterns in modern C#.

### Distributed Systems
Resilience, retries, circuit breaking, messaging and coordination concepts.

### Microservices
Small independently runnable service examples with clear boundaries.

### Algorithms
Classic and practical data structures and algorithm implementations in C#.

### Developer Tools
Utilities for developers, repositories, packages, configuration and source analysis.

### Azure
Focused cloud integrations using Microsoft Azure services.

### AI
Semantic search, embeddings, retrieval and AI-enabled .NET applications.
